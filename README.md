# Fu p

Fu p application source built with Next.js.

[Source](https://github.com/Up-to-code/fu-p) · [Issues](https://github.com/Up-to-code/fu-p/issues) · [Project directory](https://github.com/qentrah/.github/blob/main/profile/PROJECTS.md)

## Technology

Next.js, React, TypeScript, Drizzle.

## Get started

```sh
git clone https://github.com/Up-to-code/fu-p.git
cd fu-p
```

Requires Node.js and pnpm.

```sh
pnpm install
pnpm dev
```

## Available commands

| Command | Purpose |
| --- | --- |
| `pnpm dev` | Development server |
| `pnpm start` | Start the configured application |
| `pnpm build` | Build the project |
| `pnpm test` | Run the configured tests |
| `pnpm lint` | Check lint rules |
